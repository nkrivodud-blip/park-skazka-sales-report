# Отчёт по продажам Парка «Сказка» — август 2026

Одностраничный управленческий отчёт по лидам, сделкам B2C и B2B, выполнению планов менеджеров, динамике оплаченного контура и загрузке площадок.

## Публичный просмотр

[Открыть актуальный отчёт](https://nkrivodud-blip.github.io/park-skazka-sales-report/)

## Состав отчёта

- средний поток лидов и недельная динамика;
- конверсия в сделку и оплату;
- продажи оплаченного контура и выполнение планов B2C/B2B;
- планы, выполнение и остаток к добору по менеджерам;
- недельный прирост pipeline;
- сверка Bitrix, смет и ParkOps;
- утилизация площадок и аналитика дополнительных продаж.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Проверка сборки:

```bash
npm run lint
npm test
```

Статическая версия для GitHub Pages формируется скриптом `build-pages-snapshot.mjs` после основной сборки.
